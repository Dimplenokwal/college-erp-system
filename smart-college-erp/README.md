# 🎓 {VITE_APP_NAME} - Smart College ERP System

A comprehensive Full-Stack Enterprise Resource Planning (ERP) solution designed to streamline college administration, student tracking, and financial management. This project was developed as part of the MCA 2027 curriculum at **Manipal University Jaipur**.

---

## 🚀 Features

* **Dashboard**: Real-time overview of college statistics and quick navigation.
* **Attendance Tracker**: Daily attendance management with status updates (Present, Absent, Late).
* **Student Management**: Full CRUD operations to register and manage student profiles.
* **Fees Ledger**: Interactive fee tracking system with balance calculations and payment status.
* **Smart Calendar**: Integrated scheduling for academic events and deadlines.
* **Secure Authentication**: JWT-based login system for administrative access.

---

## 🛠️ Tech Stack

**Frontend:**
* React.js (Vite)
* Tailwind CSS (Styling)
* Lucide React (Icons)
* React Router DOM (Navigation)

**Backend:**
* Node.js & Express.js
* MySQL (Database)
* JSON Web Tokens (Authentication)
